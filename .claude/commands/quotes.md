1. Run `npm run shop -- quotes`.
2. Anything out 14 days with no contact is going cold: say which, and draft the follow-up (a short note in the operator's voice, to `drafts/`, never sent).
3. When one lands: `job won <ref> [--po=] [--promised=]`. When it dies: `job lost <ref> --reason=`, and the reason is data, not paperwork.
4. Win rate context comes with the command. If the shop keeps losing on price in one family of work, say so.
