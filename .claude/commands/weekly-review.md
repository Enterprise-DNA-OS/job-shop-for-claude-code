---
description: The Monday review, written from three commands. The board, the compliance position, the money, and the five things that matter this week.
---

Run these three, in this order, and write the review from what they return. Do not write anything they do not support.

```
npm run shop -- attention
npm run shop -- wip
npm run shop -- debtors
```

Then write it in this shape, no more than a page:

1. **The week in one line.** Open jobs, on the floor, quotes out and their value, WIP, owing, retentions out, hours booked (`stats` has all of it).
2. **Traceability and plant first, always.** Missing heat numbers on structural work and overdue work centre services lead the review, because they are the lines an auditor or a certifier would read.
3. **The bleeding.** Fixed quotes 80%+ eaten and unfinished, each with the decision it needs: variation, recover, or eat it knowingly.
4. **The promises.** Late jobs and shortages against promise dates, each with the call to make before the customer makes it.
5. **The money.** Finished-not-billed, overdue invoices (payment claims first, the Act is behind them), drafts never sent, retentions due, anyone over their limit. One line each with the move.
6. **The floor.** Loading by work centre, recovery by person, timesheet gaps. Full and idle both cost money.
7. **The five things to do this week.** Picked from the attention list, weighted by what breaches first and what it costs, with why each made the list.
8. **One thing to decide.** The single item that needs a person, not a process.

Add `npm run view -- shop` and `npm run view -- money` if the operator wants pages to take to a meeting. They render the same numbers in the company's brand, and they print.

Numbers come from the commands. If a number is not in the output, it does not go in the review.
