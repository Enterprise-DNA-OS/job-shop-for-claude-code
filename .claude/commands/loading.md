description: Work centre hours over the last 28 days, capacity, and the service clocks. Where the shop is full and what is legally parked.
---

1. Run `npm run shop -- loading`.
2. Read both signals: loading (where the bottleneck is, where the idle capacity is) and the service clocks (an overdue service is a HSWA compliance item, not a preference).
3. A service done gets recorded the same day: `centre service <code> [--on=]`.
4. Promising delivery dates without looking at this page is how promises get broken.
